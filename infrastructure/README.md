# 集群外基础设施

当前为目录骨架，尚未实现或部署。按 [七阶段计划](../docs/plans/README.md) 在对应阶段补充真实文件。

| 目录 | 阶段 | 负责内容 |
| --- | --- | --- |
| `opentofu/` | 00/04 | VM、模板引用、虚拟硬件与受控 State；不重复配置客体 OS |
| `ansible/` | 00/01/03 | Linux、containerd/CRI、基础服务与主机自动化；kubeadm/cephadm 复用这里的执行入口 |
| `openwrt/` | 00/02 | 旁路由、VPN、显式代理、策略路由和恢复配置 |
| `dns/` | 00 | 内部 zone、BIND 服务配置与客户端分域解析 |
| `pki/` | 00/02/06 | 公开信任链、签发/轮换说明和模板；不保存私钥 |
| `registry/` | 00/04 | 集群外 GitLab/Harbor/Nexus、生态缓存、离线物料同步与预热 |
| `cephadm/` | 03/06 | 外部 Ceph 主机、设备/OSD 与服务规格及恢复入口 |

每个实现或实验说明须包含输入、版本、操作、检查、失败恢复和清理；测试结果归根目录 `reports/`。秘密和二进制备份放受控外部位置，只保留安全引用。
