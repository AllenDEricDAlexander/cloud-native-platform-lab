# 验收用例

当前为目录骨架，尚未实现或部署。按 [七阶段计划](../docs/plans/README.md) 在对应阶段补充真实文件。

| 目录 | 阶段 | 负责内容 |
| --- | --- | --- |
| `smoke/` | 00–06 | 主机/CRI/基础服务和阶段交接的最小检查 |
| `integration/` | 01–06 | 控制器、网络、CSI、应用与自助服务完整链路 |
| `performance/` | 05/06 | 固定输入下的负载、吞吐/延迟/资源与成本 |
| `failover/` | 00–06 | VPN、控制平面、OSD、消息和节点等受控单故障 |
| `disaster-recovery/` | 03/06E | 独立备份、原状态/新集群恢复与 RTO/RPO |
| `security/` | 01/04/06A | 认证/授权、策略、供应链、轮换与检测正反用例 |

每个实现或实验说明须包含输入、版本、操作、检查、失败恢复和清理；测试结果归根目录 `reports/`。秘密和二进制备份放受控外部位置，只保留安全引用。
